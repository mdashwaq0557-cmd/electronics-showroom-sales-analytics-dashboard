# electronics-showroom-sales-analytics-dashboard
Interactive Power BI dashboard providing sales, customer, product, and store performance insights for an electronics retail showroom using Power BI, DAX, and Excel.

Electronics Showroom Sales Analytics Dashboard
Project Overview

This project presents a comprehensive Power BI Business Intelligence solution designed for an Electronics Showroom. The dashboard transforms raw retail transaction data into meaningful insights that support strategic business decisions.

The solution focuses on four major business areas:

Sales Overview
Product Performance
Customer & Payment Insights
Store & Salesperson Performance
Business Objective

The objective of this project is to help management:

Monitor sales performance
Track profitability
Analyze product demand
Understand customer behavior
Evaluate payment preferences
Measure store effectiveness
Identify top-performing salespersons
Improve operational efficiency
